# HostGuard Schemas

This directory will contain the official JSON contracts shared by HostGuard components. Schemas will provide stable, versioned definitions for data exchanged across module boundaries and persisted by the application.

Anticipated contracts include:

- `job.schema.json`
- `manifest.schema.json`
- `event.schema.json`
- `config.schema.json`

No schema is defined during Sprint 1.1.
